# JPTI Android downloads

The APK is published here automatically by the Android GitHub Actions build after the workflow completes successfully.

- Signed release: `JPTI-Android-release.apk` (requires repository signing secrets)
- Unsigned-by-production-key testing build: `JPTI-Android-debug.apk` (fallback if signing secrets are not configured)

Do not manually replace this README with build files. CI places the APK alongside it.
